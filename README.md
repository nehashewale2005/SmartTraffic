# Gamified Children’s Rights Education Platform for Teenagers

## 📌 Project Overview
Gamified Children’s Rights Education Platform for Teenagers is an interactive educational application developed to spread awareness about children’s rights through games, quizzes, and engaging activities. The platform helps teenagers learn important topics such as the right to education, equality, safety, health, and protection in a fun and interactive way.

---

## 🎯 Objectives
- To educate teenagers about children’s rights
- To provide learning through gamification
- To increase awareness using interactive quizzes and activities
- To improve engagement and knowledge retention
